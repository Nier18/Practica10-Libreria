Práctica 10

Programación para Internet

Instrucciones

Mini-sistema de registro de libros para una librería. Desarrollar un sistema con tres páginas: Inicio, con una bienvenida que permite navegar a las otras secciones; Registro, con un formulario para registrar libros nuevos; y Consulta, que despliega los libros registrados en la base de datos.

Cada libro tiene id (llave primaria), Autor, Título, Fecha de publicación e Imagen de portada. Se debe usar una base de datos relacional en Docker y la imagen se guarda en la base de datos como BLOB. Las tres páginas deben usar únicamente Bootstrap 5 para todos sus elementos y tener navegación entre ellas. El proyecto se lleva en un repositorio git local con commits conforme avanza, vinculado a GitHub.

Repositorio: https://github.com/Nier18/Practica10-Libreria

Temática

La librería se llama Cara B Libros y vende libros de música: biografías de músicos, historias de bandas y de discos.

Código

El proyecto usa tres contenedores: web (php:8.2-apache con mysqli, puerto 8080), db (mysql:8.1.0, base de datos libreria) y phpmyadmin (puerto 8081). El archivo crear_tabla.sql se carga automáticamente al iniciar el contenedor de MySQL. La portada se guarda en una columna MEDIUMBLOB.

Dockerfile

FROM php:8.2-apache
RUN docker-php-ext-install mysqli pdo pdo_mysql

docker-compose.yml

services:
  web:
    build: .
    ports:
      - "8080:80"
    depends_on:
      - db
    volumes:
      - ./html:/var/www/html
  db:
    image: mysql:8.1.0
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: libreria
      MYSQL_USER: usuario
      MYSQL_PASSWORD: "123456"
    volumes:
      - ./mysql_data:/var/lib/mysql
      - ./bd/crear_tabla.sql:/docker-entrypoint-initdb.d/crear_tabla.sql
  phpmyadmin:
    image: phpmyadmin
    ports:
      - "8081:80"
    depends_on:
      - db
    environment:
      PMA_HOST: db

bd/crear_tabla.sql

USE libreria;

CREATE TABLE libros (
    id INT AUTO_INCREMENT PRIMARY KEY,
    autor VARCHAR(100) NOT NULL,
    titulo VARCHAR(150) NOT NULL,
    fecha_publicacion DATE NOT NULL,
    portada MEDIUMBLOB NOT NULL
);

                echo "<p>Falló la conexión con MySQL: " . mysqli_connect_error() . "</p>";
            }

            $autor = mysqli_real_escape_string($con, $_POST["autor"]);
            $titulo = mysqli_real_escape_string($con, $_POST["titulo"]);
            $fecha = mysqli_real_escape_string($con, $_POST["fecha"]);
            $portada = mysqli_real_escape_string($con, file_get_contents($_FILES["portada"]["tmp_name"]));

            $sql = "INSERT INTO libros (autor, titulo, fecha_publicacion, portada)
                VALUES ('$autor', '$titulo', '$fecha', '$portada');";

            if(!mysqli_query($con, $sql)) {
                die('Error: ' . mysqli_error($con));
            } else {
                echo "<div class='alert alert-success'>El libro se ha registrado correctamente.</div>";
            }

            mysqli_close($con);
        ?>
